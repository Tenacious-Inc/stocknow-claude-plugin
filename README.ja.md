# StockNow for Claude

[English](README.md) · [한국어](README.ko.md) · **日本語**

**Claudeとの会話で、StockNowの株価、決算、ニュース、SEC開示資料を確認できます。**

StockNow MCPサーバーに接続するClaude用プラグインです。StockNowアカウントで認証すると、
企業の決算比較、開示資料や決算説明会の書き起こしの閲覧、ウォッチリスト銘柄の
ニュース確認を、会話の中で進められます。

[StockNow](https://stocknow.ai/en) · [MCPについて](https://stocknow.ai/en/mcp)

## 主な機能

| 分野 | 確認できる情報 |
| --- | --- |
| 株価・指数 | 株式の現在値、過去の価格推移、主要指数の動き |
| 決算 | 決算発表日、EPSコンセンサス予想、発表済みの実績 |
| 決算説明会 | 書き起こし全文の検索・閲覧 |
| SEC開示資料 | 10-K、10-Q、8-Kの全文 |
| ニュース | 日付・銘柄・キーワードで絞り込んだ市場速報や企業ニュース |
| 財務・スクリーナー | 財務諸表、主要指標、配当、空売り関連データ、条件による銘柄検索 |
| ウォッチリスト | StockNowアカウントに保存した銘柄 |

StockNowがホストするMCPサーバーに、**Streamable HTTP**で直接接続します。

```text
https://mcp.stocknow.ai/mcp
```

対応範囲は[StockNow MCPの案内](https://stocknow.ai/en/mcp)で確認できます。
ベータ期間中は、利用できるツールや応答形式が変更される場合があります。

## 利用条件

- インストールとログインが完了した**Claude**
- **StockNowアカウント**
- ブラウザーによる**OAuth認証**

## インストール

プラグインの一般公開を準備しています。公開後、マーケットプレイスからの
インストール方法をご案内します。

## 認証

プラグインのインストール後、Claudeの会話画面で次のコマンドを入力します。

```text
/mcp
```

1. StockNowサーバーを選択し、認証の案内に従います。
2. ブラウザーでStockNowアカウントにログインし、要求された権限を承認します。
3. Claudeに戻り、接続状態と利用できるツールを確認します。

認証情報はClaudeが管理します。APIキーやトークンを手動で入力する必要はありません。

## 使用例

認証が完了したら、自然な言葉で質問できます。

```text
NVIDIAの直近の決算をコンセンサス予想と比較して。
対象の会計四半期、数値の単位、データの出典も教えて。
```

| 調べたいこと | 質問の例 |
| --- | --- |
| 企業の決算を確認 | 「NVIDIAの直近4四半期の決算を比較して、決算説明会でnetworkingに言及している箇所を探して。」 |
| 開示資料を読む | 「Appleの最新の10-Qからサプライチェーンに関するリスク要因を探し、原文へのリンクを添えて要約して。」 |
| 市場ニュースを把握 | 「今日の半導体関連の市場速報を、各記事の公開時刻と出典を付けてまとめて。」 |
| ウォッチリストを確認 | 「ウォッチリストの中で来週決算を発表する銘柄と、そのコンセンサス予想を教えて。」 |

比較したい銘柄と期間を指定すると、より具体的に質問できます。
結果を確認する際は、基準日時、タイムゾーン、通貨、会計期間、原文の出典も確認してください。

## 接続できない場合

- **認証が必要な場合：** `/mcp`からStockNowにログインしてください。
- **アカウントの権限エラーが発生した場合：** ログインしたStockNowアカウントと、承認した接続権限を確認してください。
- **ログインに失敗する場合：** [Claude MCP認証ガイド](https://code.claude.com/docs/en/mcp#authenticate-with-remote-mcp-servers)を確認するか、サポートにお問い合わせください。

## アンインストール

```bash
claude plugin uninstall stocknow@stocknow-plugins
```

認証情報も削除する場合は、アンインストール前に`/mcp`でStockNowの
**Clear authentication**を選択してください。アカウントの接続権限の管理については、
StockNowサポートにお問い合わせください。
